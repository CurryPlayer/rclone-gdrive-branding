Personal Rclone Drive Sync

This is the application home page for a personal single-user integration using rclone to synchronize files between local storage and Google Drive.

About This Application

This application is an individual, private instance of the open-source tool rclone configured to access Google Drive via a dedicated personal OAuth 2.0 client ID.

  • Purpose: Automated personal file backup, archiving, and synchronization.
  • Target Audience: Single user / private personal use only. Not a commercial or multi-tenant service.
  • Architecture: Runs strictly as a local command-line client on the owner's machine.

Data and Privacy

This application does not collect, track, or share any personal user data. All access tokens and file contents remain entirely on the local system running rclone and Google Drive's official servers.

For complete details, please read our Privacy Policy.
